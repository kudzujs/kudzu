`61eb1b7c633a2facabb782bc654a5ad07169aeb82cf47dbccda9b9e7303a716e`.
The timing ranges overlap and require 21 samples before a final conclusion;
the RSS loss already blocks the gate. The 10,000-product run remains blocked.
