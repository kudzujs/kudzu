# Kudzu 0.9 Final Proof Audit

## Status

Work Item `0.9.0-07` is blocked as of 2026-08-19 at candidate revision
`6f296adad49e819ea72098eb687df0bad9389062`.

The complete comparison required by the benchmark contract cannot be run from
the tracked repository. Existing local suites are useful historical evidence,
but they are ignored, incomplete against the final matrix, and stale.

## Reproducibility Failure

`.gitignore` excludes the complete `benchmarks/` tree. This includes the local
runtime, resource, SVG, and commerce runners; their fixtures; their result files;
and the only local cross-framework lockfile. Consequently no Kudzu commit pins
those harness sources or results.

The ignored lock currently resolves React 19.2.8, Vue 3.5.40, Svelte 5.56.7,
Vite 8.1.5, Next.js 16.2.11, Nuxt 4.5.0, and SvelteKit 2.70.1. Those pins are
not release evidence until the harness and lock are tracked.

The public commerce repository is independently pinned at
`f2d5be1a516c539e30f7125f6870d42b1dd02ecd`, but its package lock references
Kudzu 0.8.15 and candidate testing depends on an untracked manual symlink. Its
three-sample sequential scale command also does not meet the final seven-sample
rotating protocol. The repository-owned paired runner compares Kudzu revisions,
not frameworks.

## Matrix Gaps

| Required application | Available local evidence | Release blocker |
|---|---|---|
| Content | No matched tracked multi-framework fixture | Complete C1 application is absent. |
| Stateful | Ignored Kudzu/React/Vue/Svelte runtime matrix | Astro and static sibling are absent; keyboard/focus/resilience coverage is incomplete. |
| Commerce | Frozen external and separate ignored local suites | No one pinned matrix provides every required comparator, acceptance gate, rotating run, and metric. |
| Resource | Ignored Kudzu/React/Vue/Svelte Worker/navigation matrix | Astro, repeated disposal, late release, replacement, and static exclusion coverage are incomplete. |

The available suites do not uniformly collect actual transferred and unique
session JavaScript, complete preload graphs, peak RSS, parse/execute cost,
post-journey heap, repeated-disposal heap, deterministic digests, and cold/warm
builds. Acceptance also does not precede every timing path.

## AI Migration Gate

The repository contains the intended AI-task protocol but no executable task
definitions, prompt/version pin, attempt runner, trace schema, acceptance
orchestrator, or tracked raw-attempt store. The required cost-per-success result
is therefore not reproducible.

## Required Unblock

1. Track one immutable harness and lockfile rather than copying historical
   ignored outputs into release documentation.
2. Add the missing content application and complete the stateful/resource
   comparator set with Astro and one production static-routing framework.
3. Make behavior, accessibility, keyboard/focus, cleanup, navigation, and the
   complete failure-resilience matrix pass before timing.
4. Emit every artifact, browser, build, memory, digest, and environment field
   required by `0.9-benchmark-contracts.md`.
5. Run at least seven rotating samples, increasing to twenty-one for overlapping
   timing conclusions, at 100, 1,000, and 10,000 actual emitted routes.
6. Implement and pin the AI migration task harness before claiming that gate.

Do not publish 0.9 performance or release claims until these gaps are closed.
